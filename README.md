# ヤシマ作戦 — 3D 俯瞰 作戦記録

> OPERATION YASHIMA — 3D OVERHEAD OPERATIONAL RECONSTRUCTION

第5使徒 ラミエル 迎撃作戦「ヤシマ作戦」を、テレビ特番の作戦解説 CG に相当する
**3D 俯瞰デモ**として再構成したもの。箱根カルデラの地形、ネルフ・戦略自衛隊・
関係各省庁の配置と進軍矢印、そして滑らかなカメラワークを、
特務機関ネルフの端末表示 UI の上で 4 分強の尺で通し再生する。

デフォルメはしていない。部隊は実寸（EVA 全高 40 m）、距離は実距離
（二子山 → 第3新東京市 上空 約 3.2 km）、地形は箱根カルデラの実際の
地勢配置に基づく。表示記号は SD 化した模型ではなく、実際の指揮画面と同じ
「接地リング + 標定線 + 銘板」のシンボロジーで扱っている。

---

## 動かす

WebGL2 が動くブラウザなら、静的サーバに置くだけで動く。ビルド不要、外部 CDN
参照なし（three.js はリポジトリ内に同梱）。

```bash
# 任意の静的サーバでよい
python3 -m http.server 8000
# → http://localhost:8000/
```

`file://` では ES モジュールが読めないため、必ず HTTP 経由で開くこと。

### 操作

| 操作 | 内容 |
| --- | --- |
| `Space` | 再生 / 一時停止 |
| `←` `→` | 10 秒 戻す / 送る |
| `1`–`9` | 章ジャンプ |
| `F` | 自由視点（マウスで回転・ズーム） |
| `H` | HUD 表示切替 |
| タイムライン | クリック / ドラッグでシーク、章名クリックでジャンプ |
| ×0.5 / ×1 / ×2 | 再生速度 |

コンソールからは `window.YASHIMA`（`seek(t)` / `play()` / `pause()` /
`setSpeed(s)` / `freeCam(bool)` / `camera` / `scene`）で制御できる。収録用。

## 画面（UI）

参照した意匠は 3 つ。

- **エントリープラグ 予備電源パネル**（左） — `+01`〜`+06` の目盛、
  `LIFE SUPPORT SYSTEM` / `LINK CONTROL SYSTEM` / `EXTERNAL COMMUNICATIONS`
  の 3 系統、階段状の `SEG.2`〜`SEG.6`、`BORDER LINE`、そして
  `RESERVE ENERGY REMAINING / EVA-01 : ENTRY PLUG`。
  飾りではなく実際に機能する。内部電源に切り替わる 2:43 以降、残量に応じて
  セグメントが落ち、系統が上から順に停止する。
- **MAGI 端末フレーム** — 二重罫線、角ティック、斜線ハッチ、`NERV ONLY`、
  `Code No.`、`2D/3D` バッジ。タイトル画面もこの意匠。
- **ワイヤーフレームの測地グリッド** — 地形シェーダの 1 km / 5 km グリッドと
  100 m / 500 m 等高線。

書体はタイトルカード系の重い和文明朝（`Matisse` → ヒラギノ明朝 → 游明朝 →
Noto Serif JP の順でフォールバック）を字幕・見出しに、計器類には
欧文コンデンスド・ゴシックと等幅数字を当てている。
NERV エンブレムはインライン SVG で描画（`src/ui/logo.js`）。

## 技術メモ

### 座標系と縮尺

- `+X` = 東 / `+Z` = 南 / `+Y` = 上
- **1 world unit = 100 m**、マップは一辺 280 unit = **28 km**
- 標高は垂直誇張 **×1.6**（起伏を読ませるため。水平距離・部隊間距離は実寸）

### 地形

`src/world/geo.js` の `elevationM(x, z)` が単一の情報源。地形メッシュ・
部隊の接地高さ・進軍矢印の追従高さ・カメラの地形めり込み防止が
すべて同じ関数を参照するので、破綻しない。

カルデラの径方向プロファイル、中央火口丘群（神山 1438 m / 駒ヶ岳 1356 m /
二子山 1099 m ほか）と外輪山のピーク、芦ノ湖の湖盆、第3新東京市の造成面、
相模湾の海岸線、そして富士山を合成し、fBm と尾根ノイズでディテールを乗せる。

### 状態管理

**表示状態はすべて「時刻の関数」**として定義してある（`src/director/script.js`
の `applyTracks`）。マーカーの表示区間、矢印の伸長率、市街の通電率、
予備電源残量、AT フィールド強度、薄明の進行 — いずれも `t` から直接決まる。

このため**タイムラインを巻き戻しても表示が完全に再現される**。
発射・爆発・カメラ衝撃といった一過性の演出だけを `EVENTS` として
エッジ検出で発火させ、シーク時はスキップする。

### カメラ

`src/director/camera.js`。キーフレーム間を**注視点まわりの極座標で補間**する
（半径・方位角・高さを個別に補間）ため、直線補間のように弧を横切らず、
自然な旋回になる。低周波ノイズによる微揺れと、着弾時のシェイクを重ねている。
地形へのめり込みは実測標高でクランプする。

### 描画

- three.js r169（`vendor/three/` に同梱、MIT）
- 地形・水面・市街・矢印・使徒・ビームはすべて自前の `ShaderMaterial`
- ポストプロセスは `UnrealBloomPass` + `OutputPass`
- 銘板は `CanvasTexture` のスプライト。画面比で一定サイズになるよう
  毎フレーム再スケールし、寄りのカットではリング・標定ビームを減衰させて
  実体を隠さないようにしている

## ファイル

```
index.html                 エントリ (importmap で three を解決)
src/
  main.js                  組み立て・再生ループ・入力
  style.css                NERV UI スタイル
  world/
    geo.js                 座標系・標高関数・主要地点
    noise.js               決定論的ノイズ
    terrain.js             地形メッシュ + 等高線シェーダ
    water.js               相模湾 / 芦ノ湖
    city.js                第3新東京市 + ジオフロント
    sky.js                 夜空 → 薄明
    markers.js             部隊・施設マーカー
    arrows.js              進軍矢印 / 送電経路リボン
    actors.js              ラミエル / EVA / 陽電子砲 / 射線 / 爆発
  director/
    camera.js              カメラ演出
    script.js              進行台本 (章・字幕・カメラ・マーカー・矢印・イベント)
  ui/
    hud.js                 HUD 構築と更新
    logo.js                NERV エンブレム (SVG)
vendor/three/              three.js r169 + addons (MIT)
```
