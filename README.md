# MAGI 3D 作戦記録ビューア

> VIEWER OF VARIOUS THREE-DIMENSIONAL DATA RECORDED BY THE MAGI.

『新世紀エヴァンゲリオン』の作戦を、テレビ特番の作戦解説 CG に相当する
**3D 俯瞰デモ**として再構成したもの。箱根カルデラの地形、ネルフ・戦略自衛隊・
国連軍・関係各省庁の配置と進軍矢印、そして滑らかなカメラワークを、
特務機関ネルフの端末表示 UI の上で通し再生する。

| | 作戦 | 尺 | 内容 |
| --- | --- | --- | --- |
| **A-02** | [第10使徒 迎撃戦](./zeruel.html) | 全13章 / 6分16秒 | ネルフ本部 侵攻 — 探知から初号機の覚醒まで |
| **A-01** | [ヤシマ作戦](./yashima.html) | 全9章 / 4分06秒 | 第5使徒 ラミエル 迎撃 — 全国送電から第二射まで |

`index.html` は上記 2 件を並べた MAGI データビューアの一覧画面。

デフォルメはしていない。部隊は実寸（EVA 全高 40 m / 第10使徒 全高 105 m）、
距離は実距離、地形は箱根カルデラの実際の地勢配置に基づく。表示記号は SD 化した
模型ではなく、実際の指揮画面と同じ「接地リング + 標定線 + 銘板」のシンボロジーで扱う。

## 動かす

WebGL2 が動くブラウザなら、静的サーバに置くだけで動く。ビルド不要、外部 CDN
参照なし（three.js はリポジトリ内に同梱）。

```bash
python3 -m http.server 8000
# → http://localhost:8000/
```

`file://` では ES モジュールが読めないため、必ず HTTP 経由で開くこと。

### サーバを立てずに開く

`dist/zeruel.html` / `dist/yashima.html` は three.js も含めて全部を 1 枚に畳み込んだ
単一ファイル版。ダウンロードしてダブルクリックすればそのまま動く（`file://` で可）。

```bash
npm i && npm run build   # 再生成する場合 (esbuild)
```

### スマートフォン

タッチ端末を検出すると自動で軽量設定（地形分割 176 / pixelRatio 1.1 /
ブルーム半解像度）に落ち、HUD もタッチ向けの簡易表示に切り替わる。
**横向き推奨**（横持ちではエントリープラグ予備電源パネルも縮小表示で残る）。
縦持ちでも被写体が画面外に出ないよう、画面が 16:9 より縦長のときは
横方向の画角を保ったまま垂直画角を広げる。`?q=low` `?q=mid` `?q=high` で品質を明示指定できる。

同じ Wi-Fi 内の PC でサーバを立て、スマホから PC の LAN IP を開くのが早い:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
# スマホで http://<PCのLAN IP>:8000/ を開く
```

### 操作

| 操作 | 内容 |
| --- | --- |
| `Space` | 再生 / 一時停止 |
| `←` `→` | 10 秒 戻す / 送る |
| `1`–`9` | 章ジャンプ |
| `F` | 自由視点（マウス・ピンチで回転／ズーム） |
| `H` | HUD 表示切替 |
| タイムライン | クリック / ドラッグでシーク、章名クリックでジャンプ |
| ×0.5 / ×1 / ×2 | 再生速度 |

コンソールからは `window.ZERUEL` / `window.YASHIMA`（`seek(t)` / `play()` /
`pause()` / `setSpeed(s)` / `freeCam(bool)` / `camera` / `scene`）で制御できる。収録用。

## 画面（UI）

参照した意匠は 3 つ。

- **エントリープラグ 予備電源パネル**（左） — `+01`〜`+06` の目盛、
  `LIFE SUPPORT SYSTEM` / `LINK CONTROL SYSTEM` / `EXTERNAL COMMUNICATIONS`
  の 3 系統、階段状の `SEG.2`〜`SEG.6`、`BORDER LINE`、そして
  `RESERVE ENERGY REMAINING / EVA-01 : ENTRY PLUG`。
  飾りではなく実際に機能する。第10使徒編では初号機が内部電源に切り替わる
  4:28 以降、残量（活動限界 4分59秒 の残り時間）に応じてセグメントが落ち、
  系統が上から順に停止する。
- **MAGI 端末フレーム** — 二重罫線、角ティック、斜線ハッチ、`NERV ONLY`、
  `Code No.`、`2D/3D` バッジ。タイトル画面と一覧画面もこの意匠。
- **ワイヤーフレームの測地グリッド** — 地形シェーダの 1 km / 5 km グリッドと
  100 m / 500 m 等高線。

書体はタイトルカード系の重い和文明朝（`Matisse` → ヒラギノ明朝 → 游明朝 →
Noto Serif JP の順でフォールバック）を字幕・見出しに、計器類には
欧文コンデンスド・ゴシックと等幅数字を当てている。
NERV エンブレムはインライン SVG で描画（`src/ui/logo.js`／斜線・ワードマーク・
弧を描くモットー）。

## 技術メモ

### 座標系と縮尺

- `+X` = 東 / `+Z` = 南 / `+Y` = 上
- **1 world unit = 100 m**、マップは一辺 280 unit = **28 km**
- 標高は垂直誇張 **×1.6**（起伏を読ませるため。水平距離・部隊間距離は実寸）

### 地形

`src/world/geo.js` の `elevationM(x, z)` が単一の情報源。地形メッシュ・
部隊の接地高さ・進軍矢印の追従高さ・カメラの地形めり込み防止が
すべて同じ関数を参照するので破綻しない。

### 地下構造（第10使徒編）

`src/world/dogma.js`。ジオフロント（半径 1.4 km の空洞）、四角錐台の本部、
頂部の射出口甲板、中央ドグマ縦坑と 17 層の隔壁、ターミナルドグマを実寸配置する。
床面は手前半分を落とした**切り欠き断面**なので、外から縦坑と隔壁がそのまま覗ける。
地表側は地形シェーダとビルのシェーダに開口（`uCutAmount`）を持たせ、
本部直上を透過させて地下へ視線を通す。深度計は地表からの実距離（最大 2,438 m）。

### 状態管理

**表示状態はすべて「時刻の関数」**として定義してある
（`src/director/script-zeruel.js` の `applyTracks`）。使徒・エヴァの位置、姿勢、
腕の伸長、隔壁の突破数、装甲板の貫通、予備電源残量、断面の開き具合 —
いずれも `t` から直接決まる。

このため**タイムラインを巻き戻しても表示が完全に再現される**。
爆発・閃光・カメラ衝撃といった一過性の演出だけを `EVENTS` として
エッジ検出で発火させ、シーク時はスキップする。

### カメラ

`src/director/camera.js`。キーフレーム間を**注視点まわりの極座標で補間**するため、
直線補間のように弧を横切らず自然な旋回になる。低周波ノイズによる微揺れと
着弾時のシェイクを重ねる。地形へのめり込みは実測標高でクランプするが、
ジオフロント内部のカット（`under: 1`）ではクランプを外す。

### 描画

- three.js r169（`vendor/three/` に同梱、MIT）
- 地形・水面・市街・矢印・使徒・オーラはすべて自前の `ShaderMaterial`
- ポストプロセスは `UnrealBloomPass` + `OutputPass`
- 第10使徒の腕は毎フレーム経路を張り替えるリボン（`src/world/zeruel.js`）
- 銘板は `CanvasTexture` のスプライト。画面比で一定サイズになるよう毎フレーム
  再スケールし、寄りのカットではリング・標定ビームを減衰させて実体を隠さない
